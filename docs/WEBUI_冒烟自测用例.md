# Web UI 控制台 — 冒烟自测用例

| 项目 | 内容 |
|---|---|
| 适用版本 | Web UI 一期（点击编排任务 + adb 无线连接） |
| 前提 | **无需真机**。演示模式（`--mock`）模拟设备与点击，覆盖完整事件链路 |
| 配套脚本 | `tools/webui_smoke_check.py`（纯标准库，自动执行 A 组全部用例） |
| 设计文档 | `docs/WEBUI_开发方案.md` |

---

## 0. 前置准备

```powershell
# 1. 安装 Web 依赖（首次）
pip install fastapi "uvicorn[standard]"
#   或直接双击 start_webui.bat，缺失依赖会自动安装

# 2. 启动服务（双击 bat，或命令行）
python -m uvicorn webui.app:app --host 127.0.0.1 --port 8000

# 3. 浏览器打开 http://127.0.0.1:8000
```

判定服务正常的标志：控制台出现 `Uvicorn running on http://127.0.0.1:8000`，浏览器页面加载出深色控制台。

## A 组：自动化冒烟（无真机，一条命令）

```powershell
python tools/webui_smoke_check.py
```

脚本通过 REST API 驱动全流程，全部 PASS 即表示**后端 + 子进程调度 + JSONL 事件解析 + 指标聚合 + 日志落盘**链路健康。覆盖内容：

| 用例 | 验证点 | 通过标准 |
|---|---|---|
| A1 健康检查与任务目录 | 服务可达；7 个任务全部注册 | `/api/health` 返回 `ok:true`；任务列表含 sync_click 三预设 + 3 个 legacy + adb_wireless |
| A2 演示模式双机同步 | `--mock` 子进程启动、JSONL 事件解析、指标聚合 | phase=running；≥2 个同步批次；点击成功数 >0；2 台 MOCK 设备；wait_series 有数据 |
| A3 日志增量接口 | 断线补齐契约 | `?from=seq` 返回的行 seq 全部大于 from（不重复） |
| A4 优雅停止 | 停止文件协作通道（主）→ 复用脚本 `KeyboardInterrupt` 分支 | 最终状态 `stopped` 且 **exit_code=0**（若为 failed/非 0，说明优雅停止链路异常） |
| A5 无线 ADB 演示 | 短时任务自动完成 | 自动退出，exit_code=0 |
| A6 设备占用冲突 | 同设备二次启动拦截 | HTTP 409，`detail.code=DEVICE_BUSY` |
| A7 原脚本降级 | `legacy_multi` 无设备快速失败，纯文本日志可读 | 状态 failed；日志含中文提示 |
| A8 日志落盘与编码 | `logs/webui/{run_id}.log` 存在、中文无乱码 | 文件存在且包含「机器人/同步」中文与「批次#」记录 |

**注意**：WebSocket 通道无法用标准库验证，需按 B 组在浏览器人工确认。

## B 组：浏览器手工冒烟（无真机，约 10 分钟）

### B1 演示模式端到端
1. 左侧选择「双机同步」，勾选 **演示模式（无真机模拟）**
2. 「设备选择」区无需勾选（演示模式自动生成 MOCK-1/MOCK-2）
3. 点「▶ 启动」

**预期**：
- 日志区实时滚动出现：`🚀 同步点击任务启动 | 演示模式（模拟设备）`、`✅ MOCK-x 连接成功`
- 约几秒后出现 `🎯 2 台机器人全部到位，准备同步点击...` 与 `🎯 批次#1 同步点击 2 台，同步等待 xxxms`
- 顶部指标卡：**同步批次**递增、**点击成功率**接近 100%（演示模式含约 5% 模拟失败，偶发红色 ❌ 行属正常）、**平均同步等待**有值
- 「设备状态」表格出现两台设备，在线灯绿；按钮出现时就绪灯绿，出现「结束调度」文本时就绪灯**黄**（被过滤拦下，此时不会触发点击——验证过滤逻辑）
- 「同步等待耗时」折线图随批次绘制
- 偶发出现某台设备红灯 + `⚠️ xxx 掉线...将自动重连`，几秒后恢复绿灯（演示掉线容错）

### B2 停止闭环与残留检查
1. 运行约 30 秒后点「■ 停止」
2. 日志出现 `📊 汇总: 批次N ...`、`⏩ 阶段: stopped`、`🛑 脚本停止运行`、`🏁 任务结束 (status=stopped, exit_code=0)`

**残留进程检查**（PowerShell）：
```powershell
tasklist /fi "imagename eq python.exe" /v | Select-String "sync_click"
```
预期：**无任何输出**（子进程已干净退出）。

### B3 断线重连与日志补齐
1. 重新启动一个演示任务，等日志滚动
2. **按 F5 刷新页面**
3. 预期：页面自动重连运行中的 run，日志无丢失（按 seq 补齐），指标继续更新；顶栏绿点恢复

### B4 日志过滤与下载
1. 级别下拉选 `error` → 仅显示 ❌ 点击失败行
2. 关键词输入 `批次` → 仅显示批次行
3. 点「下载」→ 得到 `{run_id}.log`，内容与页面一致（中文/emoji 正常）

### B5 运行历史
1. 启动过的任务出现在左下「运行历史」
2. 点击已结束的记录 → 切换为只读模式查看其历史日志与最终指标
3. 点击运行中的记录 → 实时接管

### B6 设备占用冲突提示
1. 演示模式启动「单机监听」后，不勾选设备、再启动一个相同预设
2. 若显式指定了相同设备地址（真机场景），应弹出 `设备 xxx 已被运行 r-xxx 占用` 的 toast

### B7 无线 ADB 演示
1. 选择「无线 ADB 连接」，勾选演示模式，点启动
2. 预期：约 3 秒内走完模拟流程，自动结束（exit_code=0），日志含 `connected to 192.168.8.197:5555（模拟）`

### B8 异常场景
| 场景 | 操作 | 预期 |
|---|---|---|
| 端口占用 | 先占用 8000 再跑 `start_webui.bat` | bat 提示端口占用与换端口用法 |
| 任务不存在 | `POST /api/runs` 传错误 task_id | HTTP 404 `TASK_NOT_FOUND` |
| 服务关闭清理 | 运行中直接关掉 bat 窗口 | 子进程随之退出，`tasklist` 无残留 sync_click |

## C 组：拿到真机后的验证清单

设备到位后按此清单快速确认真机链路（对应设计文档 12.1 节高风险项）：

| # | 场景 | 步骤 | 预期 |
|---|---|---|---|
| C1 | 设备发现 | USB 连接机器人 → 点顶栏「刷新设备」 | 设备列表出现该设备（序列号、型号、电量） |
| C2 | 无线连接 | 选择「无线 ADB 连接」（**不勾**演示模式）→ 启动 | 输出真实 IP 并 `connected`；刷新设备后出现无线地址 |
| C3 | 单机真机监听 | 选「单机监听」，勾选该设备，启动 | 机器人到位弹出确定按钮时被自动点击；日志与指标正常 |
| C4 | 双机同步 | 两台设备都无线连接后选「双机同步」，勾选 2 台 | 两台都到位才同时点击；同步等待耗时体现两机差异 |
| C5 | **停止无残留** | 运行中点停止 | `tasklist` 无残留 python/adb 子进程；设备可被下次任务立即使用 |
| C6 | **中文编码** | 检查页面与 `logs/webui/*.log` | 中文、emoji 均正常，无 `???` |
| C7 | 掉线容错 | 运行中断开一台设备网络 | 该设备红灯、任务不退出；恢复后自动重连、绿灯 |
| C8 | 「结束调度」过滤 | 让设备进入结束调度状态 | 就绪灯黄、文本显示「结束调度」、不触发点击 |

## D 组：常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| bat 启动后浏览器打不开 | 端口被占用 / 依赖安装失败 | 看窗口提示；`start_webui.bat 8010` 换端口 |
| 启动任务立即 failed | 真机未连接但没勾演示模式 | 勾选演示模式，或先建立 ADB 连接 |
| 日志乱码 | Python 版本过老（<3.10） | 升级到 3.10+ |
| 停止后仍有残留进程 | 极端情况下停止文件与 CTRL_BREAK 均未生效 | runner 已有四级降级：停止文件 → CTRL_BREAK → terminate → kill/taskkill；若仍复现，记录 run_id 反馈 |
| 页面一直「未连接」 | 服务未启动或被防火墙拦截 | 确认 uvicorn 窗口在运行；127.0.0.1 不应受防火墙影响 |
| 指标卡全为 `-` | 运行的是 legacy 原脚本（无结构化事件） | 属预期行为；换用参数化预设即有完整指标 |
